# Wispr Flow comparison, evidence boundary

This public note records the comparison method without local user paths, usage
history, or copied competitor artifacts. FlowPilot's feature and release status
belongs in [scope](../scope/competitive.md) and the
[release manifest](../release/RELEASE_ARTIFACT_MANIFEST.md).

Wispr Flow documents cloud processing and context-aware formatting in its
[privacy policy](https://wisprflow.ai/privacy) and
[Context Awareness guide](https://docs.wisprflow.ai/articles/4678293671-Context-Awareness).
FlowPilot's normal dictation path uses local speech recognition. The
[privacy disclosure](../../PRIVACY.md) explains its optional loopback services
and the limits of the network tests.

A fair product comparison still needs paired human speech, the same audio
routing and target applications, and measurements of visible delivery,
correction effort, factual errors, latency, and resource use. The
[head-to-head protocol](../testing/WISPR_FLOW_HEAD_TO_HEAD.md) lists those
measurements. It does not yet contain a matched competitive result.

Older workstation-specific artifact notes remain in Git history for provenance.
They are not a basis for claims about Wispr's current implementation, a user's
private history, or FlowPilot superiority.
